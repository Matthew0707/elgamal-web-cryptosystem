# ElGamal Web Cryptosystem
[![Открыть сайт](https://img.shields.io/badge/ОТКРЫТЬ_САЙТ-brightgreen?style=for-the-badge&logo=google-chrome&logoColor=white)](https://Matthew0707.github.io/elgamal-web-cryptosystem/)

---

##  Описание
Веб-приложение для демонстрации работы асимметричного алгоритма шифрования **Эль-Гамаля**. Проект позволяет генерировать ключи, шифровать и расшифровывать файлы любого формата прямо в браузере.

##  Функционал
*   **Генерация ключей:** Проверка числа $p$ на простоту (Миллер-Рабин), поиск первообразных корней и вычисление открытого ключа $y$.
*   **Шифрование:** Рандомный выбор сессионного ключа $k$.
*   **Работа с файлами:** Чтение и запись бинарных данных через `ArrayBuffer`. Зашифрованный файл сохраняется в формате пар 32-битных чисел.
*   **Математический движок:** Собственная реализация быстрого возведения в степень по модулю и расширенного алгоритма Евклида для поиска обратного элемента.

##  Технологии
*   **HTML5 / CSS3:** Адаптивный интерфейс в стиле Apple Design.
*   **Vanilla JavaScript:** Использование `BigInt` для работы с большими числами и криптографическими расчетами.
*   **GitHub Pages:** Автоматический деплой и хостинг.

##  Как использовать
1.  Введите простое число $p$ (нужно $> 255$ для корректной работы с байтами).
2.  Найдите первообразные корни и выберите понравившийся $g$.
3.  Задайте секретный ключ $x$ и вычислите открытый ключ $y$.
4.  Выберите файл для шифрования, задайте стартовое $k$ и получите результат.
5.  Для расшифрования используйте полученный файл и ваш секретный ключ $x$.
